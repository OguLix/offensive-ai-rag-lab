# data/poisoned

Folder ini hanya untuk dokumen serangan S2 dan S3 pada lab proyek ini.

- Setiap file wajib diawali header komentar: `# SERANGAN S2/S3: hanya untuk lab proyek`.
- Isinya hanya instruksi atau klaim palsu yang tidak berbahaya, dibuat sendiri
  untuk mengukur keberhasilan serangan lewat canary atau penanda.
- Jangan menaruh data pribadi, dokumen nyata, malware, atau instruksi yang berguna
  untuk menyerang pihak lain.
- Dokumen di sini tidak boleh masuk ke `kb_clean`. Koleksi serangan memakai nama
  terpisah seperti `kb_poisoned`.
- Jangan memindahkan atau mempublikasikan isi folder ini ke luar repo.
